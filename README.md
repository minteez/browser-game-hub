# Minteez's Browser Game Hub

A collection of browser-based HTML5 games created for **Minteez's Browser Game Hub**, engineered entirely by **Gemini AI** using detailed game design prompts written by **ChatGPT**.

The hub features a growing library of **classic 2D arcade-style games**, including both original titles and faithful recreations inspired by legendary arcade games such as **Pac-Man, Space Invaders, Snake Xenzia**, and more. Each game is designed to capture the simplicity, challenge, and nostalgic feel of classic arcade gaming while adding modern browser-friendly features.

## 🎮 About the Project

Minteez's Browser Game Hub is a personal collection of lightweight, accessible, and instantly playable browser games. The project focuses on bringing traditional arcade gameplay into a modern web environment without requiring downloads, installations, or dedicated gaming software.

Every game is built to run directly inside a modern web browser, making the collection accessible across:

- 💻 Desktop computers
- 🖥️ Laptops
- 📱 Mobile phones
- 📲 Tablets

Simply open a game in your browser and start playing.

## 🕹️ Game Collection

The repository contains a growing selection of 2D arcade-style games, including:

- Classic arcade recreations
- Arcade-inspired original games
- Retro-style action games
- Puzzle and reflex-based games
- Experimental gameplay concepts
- Various upcoming titles

Some games are directly inspired by well-known arcade classics, while others introduce completely original concepts and mechanics.

## ⚙️ Technology

The games are primarily developed using standard web technologies:

- **HTML5**
- **CSS3**
- **Vanilla JavaScript**
- **HTML5 Canvas**
- **Web Audio APIs**
- **Local Storage**

The games are designed to work without external libraries or frameworks wherever possible, keeping them lightweight, portable, and easy to run.

## 🤖 Development Process

The development workflow combines human creativity with AI-assisted development.

**Game ideas & design prompts:** ChatGPT  
**Game engineering & implementation:** Gemini AI  
**Game testing & refinement:** Minteez  
**Hosting & repository:** GitHub

Detailed game concepts and technical requirements are first developed into structured prompts. These prompts are then provided to Gemini AI to generate the HTML, CSS, and JavaScript required to build each game.

The resulting games are tested, refined, and organized into the Browser Game Hub.

## 📁 Repository Structure

Each game is maintained as an individual HTML file or game project, allowing games to be developed, tested, updated, and played independently.

The main hub connects these individual games through a central homepage, creating a unified arcade-style experience.

## 🏆 Inspired by Arcade History

The project takes inspiration from the golden age of arcade gaming and the simple philosophy of:

> Easy to learn. Difficult to master.

Games inspired by classics such as **Pac-Man, Space Invaders, and Snake Xenzia** are recreated with original implementations and redesigned presentation while preserving the fundamental gameplay concepts that made these titles memorable.

## 🚀 Project Goals

The main goals of Minteez's Browser Game Hub are to:

1. Build a diverse collection of playable browser games.
2. Experiment with different 2D game mechanics.
3. Explore AI-assisted game development.
4. Preserve the feel of classic arcade gaming.
5. Create games that are lightweight and accessible.
6. Make every game playable without installation.
7. Continuously expand the collection with new titles.
