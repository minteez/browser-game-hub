About the Hub

A collection of browser-based HTML5 games created for Minteez's Browser Game Hub, engineered entirely by Gemini AI using detailed game design prompts written by ChatGPT. The hub features a growing library of classic 2D arcade-style games, including both original titles and faithful recreations inspired by legendary arcade games such as Pac-Man, Space Invaders, and Snake Xenzia. Every game runs completely online—simply open your browser and start playing.
